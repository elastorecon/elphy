============
Installation
============


Stable release
--------------

To install MR Elastography, run this command in your terminal:

.. code-block:: console

    $ pip install elphy

This is the preferred method to install MR Elastography, as it will always install the most recent stable release.

If you don't have `pip`_ installed, this `Python installation guide`_ can guide
you through the process.

.. _pip: https://pip.pypa.io
.. _Python installation guide: http://docs.python-guide.org/en/latest/starting/installation/


From sources
------------

The sources for MR Elastography can be downloaded from the `Github repo`_.

You can either clone the public repository:

.. code-block:: console

    $ git clone https://github.com/Elastography/elphy.git

Or download the `tarball`_:

.. code-block:: console

    $ curl  -OL https://github.com/Elastography/elphy/tarball/master

Once you have a copy of the source, you can install it with:

.. code-block:: console

    $ pip install .


.. _Github repo: https://github.com/Elastography/elphy
.. _tarball: https://github.com/Elastography/elphy/tarball/master
